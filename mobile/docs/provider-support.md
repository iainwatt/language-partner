## Text and audio boundaries

The initial app deliberately uses one common speech-recognition → text adapter → device speech pipeline. It does not install WebRTC just to display a fake realtime indicator. Model selection only lists text models handled by the implemented adapters.

- [OpenAI models](https://developers.openai.com/api/docs/models/gpt-5.4-mini) and [GPT-5.4](https://developers.openai.com/api/docs/models/gpt-5.4) support the selected text API boundary. [Realtime WebRTC](https://developers.openai.com/api/docs/guides/realtime-webrtc) describes server-side session setup and temporary client credentials. A future native WebRTC transport should be another driver under the same audio owner, preserve app-owned transcript IDs, and fence callbacks across reconnects. It must obtain temporary credentials from an authenticated backend; long-lived secrets must never be bundled. No realtime client/session-token endpoint is exposed in this version because there is no client consuming it.
- [Claude's catalog](https://platform.claude.com/docs/en/models/overview) provides the selected model IDs. The implemented Claude adapter is text only. It uses the common speech pipeline and does not claim direct realtime audio support.
- [Gemini's catalog](https://ai.google.dev/gemini-api/docs/models) distinguishes text models from Live audio models. [Live API SDK guidance](https://ai.google.dev/gemini-api/docs/live-api/get-started-sdk) documents its separate session/audio transport. This app does not route text-adapter calls to a Live-only model or claim Live verification.
- [Expo speech](https://docs.expo.dev/versions/v55.0.0/sdk/speech/), [speech-recognition source](https://github.com/jamsch/expo-speech-recognition), and [React Native TextInput selection events](https://reactnative.dev/docs/textinput#onselectionchange) inform the implemented local audio and phrase-selection boundary.

The optional API backend is a supported technical route for separately billed developer API access. It is intentionally labelled that way and does not satisfy the consumer-subscription requirement.
